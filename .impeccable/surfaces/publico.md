# Public site

The visual authority is `site/portal.pin`. Do not copy tokens into DESIGN.md.

## Direction contract

THESIS: A public reading of the pipeline. Refuse a second product written by
hand and a dashboard of equal cards.

OWN-WORLD: The pinned alexendros.dev commit: iris and peach, the two self-hosted
faces, the portal button, link, skip link and header veil. No new palette.

STORY: The visitor reads what machineroom is, opens the one install guide, and
can walk phase to skill to source. Wiring and docs stay one click away.

FIRST VIEWPORT: Title, the README sentence, the public-repo line, then Install
and Default wiring. Phases follow in one column, named, not numbered.

FORM: A document with two lists, not a diagram and not a card grid. Code-first
because the world already exists in the portal. No concept seed.

CRAFT: No eyebrow. No step circles. Navigation stays in the HTML. Theme and
search enhance; they are not required to read.
